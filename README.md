# Online Cake Shop System

A JavaFX-based cake shop management system developed as part of a Software Engineering project.

The system supports customer ordering, custom cake requests, payments, order tracking, reviews, staff operations, product management, promotions, and reporting.

## Features

- Browse available cakes
- Place standard cake orders
- Request custom cake orders
- Choose delivery or in-store pickup
- Select and process payment methods
- Track order status
- Submit customer reviews
- Accept and manage customer orders
- Update order status
- Manage cake products
- Manage promotional offers
- Generate sales and order reports
